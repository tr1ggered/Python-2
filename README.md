# Python Bootcamp 02

Два консольных приложения с параллельным и асинхронным выполнением задач.

## Что я сделал

- реализовал симулятор экзамена с отдельными процессами экзаменаторов;
- синхронизировал очередь студентов и собрал итоговую статистику;
- написал асинхронный загрузчик изображений по списку URL;
- добавил проверку каталога, параллельные загрузки и таблицу результатов.

Технологии: Python, `multiprocessing`, `asyncio`, Requests, PrettyTable.
